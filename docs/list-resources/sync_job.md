# pbs_sync_job (List Resource)

Lists the sync jobs of a Proxmox Backup Server, for `terraform query`, to import them as `pbs_sync_job` resources: pulls from a remote, local pulls and pushes alike, or with `store` and `sync_direction` some of them.

PBS lists the jobs the provider may read — with `Datastore.Audit` on the job's `store`, and `Remote.Audit` on `/remote/<remote>` for a pull, `Datastore.Audit` on `remote_store` for a local pull, or `Remote.Audit` on `/remote/<remote>/<remote_store>` for a push — and leaves the others out.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the push jobs; with -generate-config-out=generated.tf
# it also writes an import block and a pbs_sync_job resource for each.
list "pbs_sync_job" "push" {
  provider         = pbs
  include_resource = true

  config {
    sync_direction = "push"
  }
}
```

### Optional

- `store` (String) List only the jobs of this datastore, such as `store1`: those whose `store` it is.
