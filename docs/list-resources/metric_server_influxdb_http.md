# pbs_metric_server_influxdb_http (List Resource)

Lists the InfluxDB HTTP metric servers of a Proxmox Backup Server, for `terraform query`, to import them as `pbs_metric_server_influxdb_http` resources. InfluxDB HTTP and UDP servers share one namespace, and each type has its own list resource.

The token is write-only and never read: the generated configuration has `token_wo = null # sensitive` and `token_wo_version = null`, which plans no change, and the server keeps the token PBS has. Fill in both only to set the token with Terraform.

Needs `Sys.Audit on /`; without it, PBS refuses the list.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the InfluxDB HTTP metric servers; with
# -generate-config-out=generated.tf it also writes an import block and a
# pbs_metric_server_influxdb_http resource for each. The servers keep the
# tokens PBS has.
list "pbs_metric_server_influxdb_http" "all" {
  provider         = pbs
  include_resource = true
}
```
