# pbs_namespace (List Resource)

Lists the namespaces of a Proxmox Backup Server's datastores, for `terraform query`, to import them as `pbs_namespace` resources: those of every datastore, or with `store` of one, at every level. The root of a datastore is not a namespace to manage, and is not listed.

PBS lists the namespaces on which the provider has `Datastore.Audit`, `Datastore.Modify` or `Datastore.Backup` — `/datastore/<store>/<namespace>` or above — and leaves the others out. It cannot list the namespaces of a datastore it cannot open: a removable datastore that is not mounted, or one in a maintenance mode that forbids reading — `offline`, or one PBS sets while it unmounts the datastore, refreshes it from S3 or deletes it. They are left out, with a warning. Without `store`, so are the namespaces of a datastore PBS fails to list for another reason, such as a datastore on a disk that is not mounted, and those of the other datastores are listed; with `store`, that fails the list.

The attributes that exist only in Terraform come out at their defaults, as after any import: `delete_groups = false` and `error_on_protected = true`, so destroying a namespace of the generated configuration fails while it holds backups.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the namespaces of datastore store1; with
# -generate-config-out=generated.tf it also writes an import block and a
# pbs_namespace resource for each.
list "pbs_namespace" "store1" {
  provider         = pbs
  include_resource = true

  config {
    store = "store1"
  }
}
```
