# pbs_apt_repository (List Resource)

Lists the entries of the APT source files of a Proxmox Backup Server node, for `terraform query`, to import them as `pbs_apt_repository` resources: every entry of `/etc/apt/sources.list` and of the `.list` and `.sources` files in `/etc/apt/sources.list.d`, disabled ones included, by file and index, as `pbs_apt_repositories` lists them. A file PBS cannot read or parse is left out, with a warning.

Needs `Sys.Audit on /`.

An entry is addressed by its index in its file: should entries before it be added or removed later, outside Terraform, the index points to another entry, and the resource then warns (see `pbs_apt_repository`). Destroying an imported entry leaves it as it is, enabled or not.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists every entry of the node's APT source files; with
# -generate-config-out=generated.tf it also writes an import block and a
# pbs_apt_repository resource for each.
list "pbs_apt_repository" "all" {
  provider         = pbs
  include_resource = true

  config {
    node = "localhost"
  }
}
```
