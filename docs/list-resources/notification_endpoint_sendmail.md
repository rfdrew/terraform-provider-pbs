# pbs_notification_endpoint_sendmail (List Resource)

Lists the sendmail notification endpoints of a Proxmox Backup Server, for `terraform query`, to import them as `pbs_notification_endpoint_sendmail` resources. Endpoints of other types have list resources of their own.

The built-in `mail-to-root` is listed too: PBS ships it, and it cannot be created or deleted, so importing it is how to manage it with Terraform; destroying the resource resets it to its built-in settings. A sendmail endpoint has no secrets: the generated configuration of every one plans no change. `send_test_on_apply` exists only in Terraform: the generated configuration sets it to `false`.

Needs `Sys.Audit on /system/notifications`; without it, PBS refuses the list.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the sendmail notification endpoints, the built-in
# mail-to-root among them; with -generate-config-out=generated.tf it also
# writes an import block and a pbs_notification_endpoint_sendmail resource for
# each.
list "pbs_notification_endpoint_sendmail" "all" {
  provider         = pbs
  include_resource = true
}
```
