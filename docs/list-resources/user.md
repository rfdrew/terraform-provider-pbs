# pbs_user (List Resource)

Lists the users of a Proxmox Backup Server, for `terraform query`, to import them as `pbs_user` resources. Every user PBS has is listed, `root@pam` and the users of other realms included, unless `realm` selects one realm.

Needs `Sys.Audit on /access/users`; without it, PBS lists only the user the provider signs in as. A user's password is write-only and never read: the generated configuration has `password_wo = null # sensitive` and `password_wo_version = null`, which plans no change, and the user keeps its password. Fill in both only to change the password of a `pbs` user with Terraform, as `pbs_user` describes.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the users; with -generate-config-out=generated.tf it
# also writes an import block and a pbs_user resource for each.
list "pbs_user" "pbs" {
  provider         = pbs
  include_resource = true

  config {
    realm = "pbs"
  }
}
```
