# pbs_datastore (List Resource)

Lists the datastores of a Proxmox Backup Server, for `terraform query`, to import them as `pbs_datastore` resources: those in a directory, removable ones, mounted or not, and those on S3.

PBS lists the datastores on which the provider has `Datastore.Audit`, `/datastore/<name>` or above, and leaves the others out.

The attributes that exist only in Terraform — `reuse_datastore`, `overwrite_in_use`, `destroy_data` and `keep_job_configs` — come out at their defaults, `false`, as after any import: destroying a datastore of the generated configuration keeps its backups, and deletes its jobs and ACL entries. Set `keep_job_configs` before destroying one whose jobs should stay.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the datastores; with -generate-config-out=generated.tf
# it also writes an import block and a pbs_datastore resource for each.
list "pbs_datastore" "all" {
  provider         = pbs
  include_resource = true
}
```
