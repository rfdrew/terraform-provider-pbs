# pbs_apt_standard_repository (List Resource)

Lists the standard APT repositories of Proxmox Backup Server that a node has, for `terraform query`, to import them as `pbs_apt_standard_repository` resources: those of `enterprise`, `no-subscription` and `test` that an entry of the node's source files references, enabled or not, as PBS reports them. A standard repository without an entry is not listed.

Needs `Sys.Audit on /`.

~> **Destroying an imported standard repository disables it**: PBS cannot remove an entry, so destroying a `pbs_apt_standard_repository` disables every enabled entry of the repository — and removing its resource block after the import plans exactly that. To stop managing a repository and keep it enabled, remove it from the state instead (`terraform state rm`, or a `removed` block with `destroy = false`). Manage each repository with one resource only.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the standard repositories the node has; with
# -generate-config-out=generated.tf it also writes an import block and a
# pbs_apt_standard_repository resource for each. Destroying such a resource
# disables its repository.
list "pbs_apt_standard_repository" "all" {
  provider         = pbs
  include_resource = true
}
```
