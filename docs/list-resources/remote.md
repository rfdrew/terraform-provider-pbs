# pbs_remote (List Resource)

Lists the remotes of a Proxmox Backup Server, for `terraform query`, to import them as `pbs_remote` resources.

PBS lists the remotes on which the provider has `Remote.Audit`, `/remote/<name>` or above, and leaves the others out.

A remote's password is write-only and never read: the generated configuration has `password_wo = null # sensitive` and `password_wo_version = null`, which plans no change, as the imported remote keeps the password PBS has. Set both before a change that replaces the remote, of `name`: PBS creates a remote only with its password.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the remotes; with -generate-config-out=generated.tf it
# also writes an import block and a pbs_remote resource for each, with
# password_wo null: an imported remote keeps the password PBS has.
list "pbs_remote" "all" {
  provider         = pbs
  include_resource = true
}
```
