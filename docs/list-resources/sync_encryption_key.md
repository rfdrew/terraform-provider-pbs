# pbs_sync_encryption_key (List Resource)

Lists the sync encryption keys of a Proxmox Backup Server, PBS 4.2 or newer, for `terraform query`, to import them as `pbs_sync_encryption_key` resources; archived keys are listed too. `pbs_sync_encryption_key` needs PBS 4.2, so on an older server the list is empty, with a warning, rather than failing — also on PBS 4.1.9 and later 4.1 releases, which have sync encryption keys already.

Listing needs `Sys.Audit` on `/system/encryption-keys/<id>` for each key: PBS leaves out the keys the provider's user or token may not audit.

PBS never returns a key itself, so the generated configuration has `key_wo = null # sensitive` and `key_wo_version = null`, which plans no change and keeps the key PBS has. Leave them null: filled in, they replace the key unless `key_wo` holds the same one, as `key_wo_version` describes. **Keep a copy of every key outside PBS**: the backups a key encrypted cannot be restored without it.

~> **Destroying an imported key deletes it**, archiving it first, as destroying any `pbs_sync_encryption_key` does — and removing its resource block after the import plans exactly that. PBS refuses to delete a key a sync job holds. To stop managing a key, remove it from the state instead.

-> List resources need Terraform 1.14 or later; OpenTofu and older Terraform releases do not support them. Declare `list` blocks in a `.tfquery.hcl` file and run `terraform query`; `terraform query -generate-config-out=generated.tf` writes an `import` block and a `resource` block for each object, which `terraform plan` then imports. Sensitive attributes are null in the results and in the generated configuration, and write-only ones are never read, so they are null there too; the text above says which of them, if any, the generated configuration needs filled in.

## Example Usage

```terraform
# terraform query lists the sync encryption keys (PBS 4.2 and later),
# archived ones included; with -generate-config-out=generated.tf it also
# writes an import block and a pbs_sync_encryption_key resource for each.
# The keys themselves are never read.
list "pbs_sync_encryption_key" "all" {
  provider = pbs
}
```
